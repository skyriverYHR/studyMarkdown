# web

## servlet 编码问题

*** jsp页码 ***
```<%@ page contentType="text/html;charset=UTF-8" language="java" pageEncoding="UTF-8" %>```
* ```contentType``` 告诉浏览器的响应头和编码类型
* ```language``` 脚本语言
* ```pageEncoding``` 针对jsp编译器(如Tomcat)


## 是否允许jsp写入变量

```<%@ page isELIgnored="false" %>```
* true 表示忽略变量
* false 表示读取变量

```${pageContext.request.contextPath}```
* 获取当前路径



# 数据库/jdbc

## servlet找不到jdbc jar包导致数据库无法访问

* 原因servlet是一个封闭房间无法全局搜索
* 解决：需要手动声明
    ```java
    //手动添加jar包 servlet只会在自己的环境下寻找不会在电脑上搜索
            try {
                // 这一行在 Web 环境中至关重要
                Class.forName("com.mysql.cj.jdbc.Driver");
            } catch (ClassNotFoundException e) {
                e.printStackTrace();
                resp.getWriter().println("Fatal Error: MySQL Driver Not Found in Library!");
                return;
            }
    ```
