## 滑动窗口

* 常见：双针遍历
* 越长越合法/越短越合法 --- 长度增加/减少不会破坏合法性，反而可能继续保持或更容易满足条件。***通常是达到要求后需要循环继续遍历符合条件的内容继续精进答案```

> [!Tip]
> 处理越长/短越合时，要根据满足条件去满足窗口大小；  
> 越短越合：窗口要在条件内尽量长  
> 越长越合：窗口要在条件内尽量小（因为数组往外延伸都满足）

### 4.和相同的二元子数组（恰好滑动窗口）
```https://leetcode.cn/problems/binary-subarrays-with-sum/description/```

**原理：**
```java
/*
考虑以下集合关系：
所有 和 ≤ goal 的子数组
包含了：
→ 和 = 0 的子数组
→ 和 = 1 的子数组
→ …
→ 和 = goal 的子数组
所有 和 ≤ (goal − 1) 的子数组
包含了：
→ 和 = 0 的子数组
→ 和 = 1 的子数组
→ …
→ 和 = goal−1 的子数组
那么，两者相减：
{和 ≤ goal} − {和 ≤ goal−1} = {和 = goal}
*/
```




## 二分查找
> [!mportant]
> 左指针严格指向已经判断后小于要求的部分（渲染为红色）  
> 右指针严格指向大于等于要求的部分（渲染为蓝色）  
> 窗口`[left,right]`必须是一个闭区间，区间内不能有不满足条件的值    
> 开闭区间可以互相转化  

```java
int x;
int target;
int[] nums;
public int lb(int[] nums, target){
  //闭区间【left,right】
  int left = 0;
  int right = nums.length-1;
  while (left <= right){
      int middle = (right + left)/2;
      if (nums[middle] < target){
          left = middle + 1;
      }
      else {
          right = middle - 1;
      }
  }
  return left;
}
//lb(x,target)
/*
1.  x >= target  lb(x,target) 大于等于target的数
2.  x > target   lb(x,target+1)  大于目标的第一个数
3.  x < target  lb(x,target)-1 小于目标的第一个数
4.  x <= target   lb(x,target+1)-1  小于等于目标的第一个数
*/
```

### 位运算

* ```&```按位与运算```5&3 -> 101 & 011 = 001``` 两位都为1为1
* ```|```按位或运算```5|3 -> 101 | 011 = 111``` 任意为1为1
* ```^```按位异或运算
* ```~```按位取反
* ```<<```左移：高位丢弃，地位补零
* ```>>```算术右移：符号位不变，高位补符号位

> [!Tip]
> 浮点数不支持位运算  
> char 也可以参与
