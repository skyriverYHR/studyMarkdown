# 

* 原码： 一个数据在计算机中存储的编码（二进制）
* 反码： 0与1互换 符号位除外
* 补码： 反码+1

        计算机如何知道一串二进制数表示多少

        -2

        原码 1 0000010
        反码 1 1111101
        补码 1 1111110

        计算机通过补码存储 ——> -(2^8) + 2^7 + 2^6 + 2^5 + 2^4 + 2^3 + 2^2 + 2^1 + 2^0;

        (未声明的操作类型) int a = 1;

        (未声明的操作类型，怎么操作解码) int：存储空间  a:变量名 1数据
