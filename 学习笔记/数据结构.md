### 二叉树（和树类似但不是）

所有的树都能够转化成为唯一对应的二叉树；

* 二叉树
  * 最多拥有两个节点（一定要区分，无论是一个节点还是两个 ）
    * 左子树
    * 右子树
  * 性质：
    * 在i层的二叉树上最多拥有2**(i-1)个节点
    * 对于任何一个二叉树，如果的叶子数n，度为2的节点为a ， n = a + 1;
    * 完全二叉树
      * 具有n个节点的完全二叉树的深度为  以log2-n的底数 + 1
      * 完全二叉树中第i个节点的子节点一定是2i和2i+1
  * <font color = "yellow">特例</font>
    * 满二叉树
      * 每一层都是满的
    * 完全二叉树
      * 确保i层的节点，i-1层的节点是满的（每一个满二叉树的节点和满二叉树一一对应）

#### 最优二叉树（哈夫曼树）

路径最短的树
完全二叉树的路径一定最短：

* <font color = "Orange">作用</font>
  * 在分支中缩短运行的时间效率;提高代码的运行速度

* 路径长度
  * 根节点到每一个节点经过的线段和；

* 权：
  * 将树中的节点赋予一个有着某种含义的数值，则这个数值称为该节点的权

* 节点的带权路径长
  * 从根节点到该节点之间的路径长度于该节点的权的乘积；
* 树的带权路径长
  * 从根节点到该叶子节点之间的路径长度于该节点的权的乘积；

    * 记录路过的编码左右值路径是唯一的（没有一个字符需要经过别的字符）

##### 关键路径问题

* 找到所用权重最长的路径
* 整个工程的活动时间是关键路径长

* 关键路径 -> 没有时间余量的活动称为关键事件 -> 关键路径由关键事件组成
  * 事件时间余量 -> 最晚发生时间-最早发生时间
    * 最早发生：下一个节点的最早发生时间,为上一（多）个顶点最早发生时间+权值（最大值）
    * 最晚发生：从汇点开始往回，保证前一个活动一定能完成 -> 上一（多）个节点的最小发生时间，等于下一个节点的权值-上个节点到此节点的权值（最小值）
    * 汇点的：最早发生 = 最晚发生

  * 活动时间
    * 最早发生：前事件的最早发生时间
    * 最晚发生：后事件的最迟时间 - 权值

### 堆排序
特点
* 利用了树的数据结构并且通过数组实现存储

完全二叉树排序

* 根要大于左右孩子（大根堆）反之是小根堆（要统一规律）
  * a1 > a2,a3 -> a2 >a3,a4 指的是节点
* 通过堆组成树组成树

```fow
void HeapAdjust(elem R[] , int s ,int m){
  //已知R[s...m]中记录的关键词除了R(s)之外均满足定义，本函数调整R[s]的关键词，使得R[s...m]成为一个大根堆
  rc = R[s];
  for (j = 2*s; j <= m j*=2){//沿着key较大的节点向下筛选
    if(j < m && R[j] < R[j+1]){
      j++
    }
    if (rc >= R[j]){
      break;
    }
    R[s] = R[j];
    s = j;
  }
  R[s] = rc;
}
```

父节点x = 当前节点n n/2； 

```flow
void HeapSort (elem R[]){ //对R[1]到R[n]进行排序
  int i;
  for(i = n/2; i>= 1 ; i--){
    HeapAdjust(R,i,n) //创建初始堆
```
